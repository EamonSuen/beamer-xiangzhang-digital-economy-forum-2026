\section{理论模型}

\begin{frame}{模型要回答什么问题？}
  在展示实证结果之前，我们想先用一个简单的模型把故事的逻辑讲清楚。

  \vspace{0.5em}
  模型需要同时解释三件事：
  \begin{itemize}
    \item 为什么数字化会让一些企业\emph{减少}实物投资，却\emph{增加}研发投入？
    \item 什么样的企业更容易减少实物投资——融资受限的，还是融资能力过强的？
    \item 这种调整对企业效率意味着什么？
  \end{itemize}

  \vspace{0.5em}
  我们的做法是把\emph{资产抵押（ABL）}和\emph{现金流抵押（CFL）}同时放在一个两期模型里，让企业在双重摩擦下做投融资决策。
\end{frame}

\begin{frame}{模型设定：企业的经营现金流}
  企业在一个时期内的可验证经营现金流来自两个部分：

  \[
    \pi_i \;=\; \underbrace{A_i K_i^\alpha}_{\text{当期生产现金流}}
    \;+\;
    \underbrace{G_i^\beta L_i^{1-\beta}}_{\text{创新产出}}.
  \]

  \begin{itemize}
    \item 第一部分是存量实物资本 $K_i$ 带来的当期生产收入；
    \item 第二部分是研发资本 $G_i$ 和研发人员 $L_i$ 共同创造的创新产出。
  \end{itemize}

\end{frame}

\begin{frame}{融资约束：双通道并存}
  企业的预算约束是：

  \[
    (1-\theta_i)K_i + (1-s)\kappa G_i + wL_i
    \;\leq\;
    \mu(d_i)\pi_i.
  \]

  \vspace{0.4em}
  \begin{columns}[T]
    \column{0.5\textwidth}
      \begin{methodbox}{资产抵押通道（ABL）}
        $\theta_i$ 是\emph{资产可抵押比例}——设备厂房有多少能拿来担保。比例越高，同样的 $K_i$ 能撬动的外部融资越多。
      \end{methodbox}
    \column{0.5\textwidth}
      \begin{methodbox}{现金流抵押通道（CFL）}
        $\mu(d_i)$ 是\emph{现金流可契约化比例}——经营现金流有多少能被银行认可。数字化水平 $d_i$ 越高，$\mu(d_i)$ 越大。
      \end{methodbox}
  \end{columns}
\end{frame}

\begin{frame}{核心结果：一个有方向的"门槛"}

  从模型的一阶条件出发，我们可以定义一个门槛值：
  \[
    \overline{MPK}_i(\lambda_i)
    \;=\;
    \frac{\tilde{\delta}_{K,i}+\lambda_i\bigl[1-\theta_i(d_i)\bigr]}
         {1+\lambda_i\,\mu(d_i)}.
  \]

  \vspace{0.3em}
  直观理解：\emph{企业应该把实物资本推到什么水平为止？}门槛值给出了答案——它取决于融资约束的影子价格 $\lambda_i$、资产的可抵押性 $\theta_i$、以及现金流的可契约化程度 $\mu(d_i)$。
\end{frame}

\begin{frame}{门槛的含义：一个关键的不对称性}
  根据 $\theta_i$ 和一个临界值 $\overline{\theta}=1-\mu(d_i)\tilde{\delta}_{K,i}$ 的关系，企业分成两类：

  \vspace{0.5em}
  \begin{columns}[T]
    \column{0.5\textwidth}
      \begin{methodbox}{融资受限型（$\theta_i<\overline{\theta}$）}
        实物资本本来被融资不足压在效率水平以下。数字化缓解了融资约束，企业获得扩张空间，\textbf{增加}有形资本投入。
      \end{methodbox}
    \column{0.5\textwidth}
      \begin{cautionbox}{抵押囤积型（$\theta_i>\overline{\theta}$）}
        实物资本已被融资动机推到超出生产需要的水平。数字化让企业不再需要那么多抵押品，反而\emph{收缩}有形资本。
      \end{cautionbox}
  \end{columns}

  \vspace{0.6em}
  \begin{findingbox}{一个很有意思的预测}
    尽管两类企业在实物资本上的调整方向\emph{截然相反}，但它们在研发投入上的扩张是\emph{一致的}——数字化无条件地推动知识资本增长。
  \end{findingbox}
\end{frame}



\begin{frame}{门槛的一个隐含含义：资本越老，越容易囤积}
  门槛 $\overline{\theta}$ 还有一个值得展开的性质：

  \begin{itemize}
    \item $\overline{\theta}$ 会随着\emph{资本老化程度上升而下降}；
    \item 也就是说，\emph{设备越老旧的企业，门槛越低，越容易掉进抵押囤积区域}；
    \item 这个预测的好处是它可以直接拿到数据里去检验——我们用资本年龄做分组变量，看老资本企业和新资本企业的反应是否不同。
  \end{itemize}
\end{frame}

\begin{frame}{从模型到实证：四个可检验的预测}
  总结一下，模型给了我们四个可以拿到数据里去验证的命题：

  \begin{enumerate}
    \item \textbf{基准预测}：贯标后，企业实物资本支出下降、研发投入上升。
    \item \textbf{囤积出清}：CapEX 的收缩，应该集中出现在事前抵押融资依赖更强、超额资本存量更高的企业身上。
    \item \textbf{信息替代}：传统抵押空间越紧、关系型软信息越稀缺的市场，贯标带来的信贷扩张应该越明显。
    \item \textbf{效率含义}：如果这不是被动紧缩，应该看到 MRPK 离散度下降、投资对成长机会更敏感、老资本企业调整更剧烈。
  \end{enumerate}

  \vspace{0.4em}
  接下来我们一个一个看数据上是否支持这些预测。
\end{frame}
