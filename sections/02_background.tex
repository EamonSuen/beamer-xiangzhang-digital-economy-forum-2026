\section{制度背景与机制}

\begin{frame}{两化融合贯标：不只是"数字化"三个字}
  先交代一下制度背景。大家可能觉得"数字化"这个词有点虚，但两化融合管理体系把它变得很具体。

  \begin{itemize}
    \item 这套体系把企业的数字化从零散的技术改造，变成了一套\emph{可复制、可审计、可持续改进}的组织流程。
    \item 也就是说，贯标不是企业自己说"我在做数字化"，而是要经过第三方审核认证的。
    \item 对我们研究者来说，这提供了一个关键优势：\emph{认证通过日是可观测的，试点又是分批推进的}。
  \end{itemize}

  \begin{methodbox}{识别上的含义}
    两化融合贯标不是一个抽象的概念，而是一个在企业层面可以清楚观察到的数字化治理能力认证——这正是 staggered DID 需要的处理变量。
  \end{methodbox}
\end{frame}

\begin{frame}{无预期假设是否天然满足?}
  我们从四个角度记录了预期信号的存在：
  \begin{itemize}
    \item \textbf{制度层面}：顶层战略从党的十六大就开始提了，2008 年起通过试验区逐步落地；
    \item \textbf{激励层面}：A 股上市公司拿到的相关政府补助，从 \textbf{2010 年}起就显著上升了，远早于 2014 年贯标试点启动；
    \item \textbf{舆论层面}：主流官方媒体的相关讨论在 2008--2010 年间就已经达到了样本期峰值；
    \item \textbf{政策层面}：很多地方在认证完成前就把贯标结果纳入了扶持和采购加分。
  \end{itemize}

  \vspace{0.3em}
  因此，本文在基准事件研究中仍以认证完成节点作为统一、可观测的事件时间，但允许在该节点之前的若干期内存在预期反应；后文将参考现有文献的一致做法（Nagengast and Yotov，2025；Bertolotti，2026），通过事前趋势诊断和有限预期窗口设定调整预期窗口长度，并检验主结论对该窗口设定的敏感性。
\end{frame}

\begin{frame}{融资结构的现实：不是只有抵押一条路}
  对融资约束建模最常见的方法包括基于现金流的约束（Clementi and Hopenhayn，2006）与基于资产的约束（Rampini and Viswanathan，2010）。
  回到融资问题。大家可能有一个印象——中国企业借钱主要靠抵押。但这个画面正在改变。

  \begin{itemize}
    \item Lian 和 Ma（2021）发现：美国大约 \textbf{80\%} 的企业债务，其背后是\emph{经营现金流}而不是资产抵押在支撑；
    \item 万晓莉等（2025）记录了中国也在发生类似的转变：从抵押物导向转向现金流导向。
  \end{itemize}

  \vspace{0.4em}
  所以现实中的企业融资，其实是\emph{两条通道并存}：
  \begin{itemize}
    \item \textbf{资产抵押（asset-based lending, ABL）}：靠厂房、设备、土地做担保；
    \item \textbf{现金流抵押（cash flow-based lending, CFL）}：靠经营收入、现金流做还款保障。
  \end{itemize}

  \vspace{0.3em}
  这就构成了我们分析框架的逻辑出发点。
\end{frame}

\begin{frame}{核心机制：数字化让"软"信息变"硬"}
  那数字化是怎么改变这个结构的？

  \begin{block}{一句话机制}
    数字化提升经营活动的标准化、可记录性与可验证性，让原本银行"看不清、信不过"的内部经营信息，变得可以进入信贷契约。
  \end{block}

  \vspace{0.5em}
  这件事的后果是系统性的：
  \begin{itemize}
    \item 当现金流信息可以被银行识别和定价，外部融资对实物抵押品的依赖性就下降了；
    \item 那些原本为了融资而囤积低效实物资本的企业，维持冗余产能的激励就减弱了；
    \item 所以，实物投资收缩\emph{不一定是坏事}——它可能是抵押囤积出清之后、资源向研发重新配置的结果。
  \end{itemize}
\end{frame}
