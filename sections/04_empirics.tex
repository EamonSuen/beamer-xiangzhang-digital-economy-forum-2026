\begin{frame}{机制一：抵押囤积的识别}
  \begin{itemize}
    \item 核心前提：部分企业在贯标前持有超出生产基本面所需的实物资本。
    \item 构造“事前囤积楔子” PH：控制产出规模、劳动投入、行业与年份后，企业有形资本存量的超额残差。
    \item 可证伪推论：
      \begin{itemize}
        \item 高 PH 企业在事前更依赖抵押融资。
        \item 贯标后的 CapEX 收缩集中在高 PH 企业。
        \item 出清主要通过控制新增边际投资，而非处置既有存量资产。
      \end{itemize}
  \end{itemize}
\end{frame}

\begin{frame}{机制二：借款能力与抵押替代}
  \begin{itemize}
    \item 贯标后企业总贷款规模显著上升，说明外部借款能力增强。
    \item 信贷扩张主要集中于短期贷款，与银行在信息仍不完全时通过续贷频率进行动态监督一致。
    \item 剩余抵押空间越小的企业，贯标带来的总贷款、抵押贷款和短期贷款扩张越强。
    \item 这说明信息可验证性在边际上替代了实物抵押的增信功能，而非只是普遍扩大融资规模。
  \end{itemize}
\end{frame}

\begin{frame}{机制三：银行竞争与软信息替代}
  \begin{itemize}
    \item 若数字化发挥“信息硬化”作用，效应应在关系型软信息更稀缺的信贷市场更强。
    \item 使用城市前三大、前五大银行分支机构集中度刻画地方信贷市场结构。
    \item 结果显示：银行竞争越激烈、集中度越低，贯标对企业信贷获取和抵押贷款的促进作用越强。
    \item 企业端的抵押替代与银行端的软信息替代相互印证。
  \end{itemize}
\end{frame}

\begin{frame}{机制四：融资条件改善的微观后果}
  \begin{itemize}
    \item 投资对现金流敏感性下降：企业投资不再高度依赖内部现金流。
    \item 预防性储蓄动机减弱：企业不必为未来融资不确定性过度持有现金。
    \item 信贷边界拓宽并未导致无差别扩张，而是使低效抵押囤积的必要性下降。
    \item 这解释了为何融资改善可以同时伴随 CapEX 收缩与 RD 扩张。
  \end{itemize}
\end{frame}

\begin{frame}{机制五：资本配置效率改善}
  \begin{itemize}
    \item 高 MRPK 企业在贯标后边际回报回落，行业内资本错配程度下降。
    \item 企业投资对滞后一期 Tobin's Q 的敏感性上升，说明投资筛选更依赖成长机会。
    \item 资本年龄越高的企业，贯标对 CapEX 的抑制越强，与老旧资本上的抵押囤积出清一致。
    \item 实物投资收缩不是实体经济空心化，而是从规模扩张导向转向回报导向。
  \end{itemize}
\end{frame}

\begin{frame}{经济含义}
  \begin{itemize}
    \item 数字化的投资效应不是简单“扩张投资规模”，而是改变资本配置的契约基础。
    \item 当信息可验证性足以支撑债务契约时，信贷供给可部分脱离实物抵押依赖。
    \item 实物投资下降需要与研发扩张、MRPK 离散度下降和投资--Q 敏感性上升一起评价。
    \item 本文为宏观层面固定资产投资放缓与研发占比上升提供了微观解释。
  \end{itemize}
\end{frame}
